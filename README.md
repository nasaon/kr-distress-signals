# 부실 신호 연구 — 자본잠식 기업의 회생 분석과 상장폐지 경고 신호

재무제표에서 "이 회사가 위험하다"는 신호를 얼마나 미리 읽을 수 있는지 두 방향으로 확인한 기록입니다.

1. **자본잠식 회생 분석**: 자본잠식에 빠진 상장사 중 어떤 회사가 다시 살아나는가 (`capital-impairment/`)
2. **상장폐지 경고 신호**: 퇴출된 회사들은 상장폐지 직전 사업보고서에서 이미 신호를 보였는가 (`delisting/`)

## 1. 자본잠식 회생 분석

`capital-impairment/the_way_to_survive.ipynb` (V8)

| 단계 | 내용 |
|---|---|
| 위기 식별 | 완전자본잠식(자본총계 < 0) · 부분자본잠식 · 위험 단계(3년 연속 영업적자)로 나누고, 이후 3년 연속 영업흑자를 '회생 성공'으로 정의 |
| 변수·전처리 | 부채비율·자기자본비율·ROA·영업현금흐름 비율·이자보상배율 등 재무비율, 극단값 처리 |
| 산업 구분 | 표준산업분류(KSIC) 대분류로 묶은 뒤 산업 안에서 재무 특성으로 다시 군집화(12개 군) |
| 원인 분해 | 순이익이 줄어든 원인을 영업이익 · 재무비용 · 기타로 나눠 표시 |
| 예측·해석 | 회생 여부 분류 모형 + SHAP으로 어떤 비율이 영향을 줬는지 표시, 재무 구조가 비슷한 성공 기업 찾기 |
| 보고서 | 기업별 PDF 보고서 자동 생성 — 예시 `reports/유수홀딩스_재무분석보고서.pdf`, 요약 `reports/V7_Executive_Summary.pdf` |

**결과와 한계**: 대상 기업은 4,281곳입니다. 학습 데이터 AUC는 1.00인데 테스트 AUC는 0.846이고, 테스트 AP(평균정밀도)는 0.055입니다. 학습 데이터에 지나치게 맞춰졌고(과적합), 회생 사례가 적은 불균형 데이터라 정밀도가 낮습니다. 그래서 이 모형의 점수는 판단에 쓰지 않고, 기업별로 원인을 분해해 보는 도구로 썼습니다.

원본 데이터(상장사 재무 데이터 CSV, 약 100MB)는 용량과 배포 조건 때문에 넣지 않았습니다. 노트북의 출력(표·그림)은 남겨 두었습니다.

## 2. 상장폐지 경고 신호

`delisting/kr_delist_study.py`, 결과 `delisting/KR_DELIST_LOG.txt`

- 2016~2026년 주권 상장폐지 441건 중 합병·이전 등을 뺀 **퇴출성 상폐 281건**(연평균 약 26건)을 골랐습니다.
- 최근 120곳의 **상폐 전년 사업보고서**(OpenDART)를 확인했더니 **82곳(68%)**이 이미 경고 신호를 보였습니다. 신호별 건수(겹침 포함): 2년 연속 영업적자 56, 사업보고서 미제출 23, 완전자본잠식 12, 자본잠식 50% 이상 3.
- 같은 기준을 시가총액 상위 313종목에 적용하자 '2년 연속 영업적자'가 투자 중인 성장 기업(2차전지·로봇 등) 33곳을 잘못 걸렀습니다. 그래서 실제 규칙에는 **자본잠식만** 남겼습니다.

실행하려면 OpenDART 인증키가 필요합니다.

```bash
pip install -r requirements.txt
set DART_API_KEY=발급받은_키        # PowerShell: $env:DART_API_KEY="..."
python delisting/kr_delist_study.py
```

## 한계

- 상장폐지된 회사의 주가 경로는 무료 데이터에 없어, 이 연구는 재무 신호의 '사전 포착률'까지만 다룹니다.
- 경고 신호 68%는 퇴출 사례 120곳 기준입니다. 신호가 있었지만 퇴출되지 않은 회사(오탐)는 시가총액 상위 313종목에서만 확인했습니다.

## 만든 방법

AI 코딩 도구(Claude Code)를 사용해 만들었습니다. 자본잠식 분석은 재무데이터분석 수업에서 배운 내용을 바탕으로 직접 넓힌 개인 프로젝트입니다.
